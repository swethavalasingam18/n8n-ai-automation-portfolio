# 🧠 RAG Knowledge Base Chatbot

## 📌 Overview

An AI-powered knowledge base chatbot built with n8n.

The workflow uses an AI Agent to answer questions using information retrieved from a vector database, allowing the chatbot to work with a specific knowledge base instead of relying only on the language model.

## 🔄 Workflow

User Question
↓
n8n Chat Trigger
↓
AI Agent
↓
Google Gemini
↓
Qdrant Vector Store
↓
Knowledge Retrieval
↓
AI Response
