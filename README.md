## ⭐ Featured Projects

### 1. 🧠 RAG Knowledge Base Chatbot

An AI-powered chatbot that uses a knowledge base to answer questions using Retrieval-Augmented Generation.

**Technologies:** n8n · AI Agent · Google Gemini · Qdrant · Embeddings · Memory

---

### 2. 👥 AI CRM Lead Management

An AI-powered CRM automation that analyzes incoming lead information, generates lead scores, categories, priorities and summaries, stores the results in Google Sheets, and sends an automated email response.

**Technologies:** n8n · AI Agent · Google Gemini · JavaScript · Google Sheets · Gmail

---

### 3. 📩 Website Contact Form Automation

An automated workflow that receives website contact-form submissions, uses AI to classify and prioritize them, stores the information in Google Sheets, and sends email notifications.

**Technologies:** n8n · Webhooks · AI · JavaScript · Google Sheets · Gmail

---

### 4. 💬 AI Chatbot with Memory

A conversational AI chatbot built with n8n that uses an AI Agent, Google Gemini, and conversation memory to maintain context across interactions.

**Technologies:** n8n · AI Agent · Google Gemini · Memory

---

### 5. ✉️ AI Email Generator

An AI-powered email automation that takes information from Google Sheets, generates a professional email using an LLM, processes the output, and sends the email automatically through Gmail.

**Technologies:** n8n · LLM · OpenRouter · Google Sheets · JavaScript · Gmail
